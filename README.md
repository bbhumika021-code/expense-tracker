# Expense Tracker

This is a simple expense tracker web application that I made using Python and Flask.

I made this project to practice working with Flask, HTML, CSS and SQLite and to understand how a basic web application works with a database.

## What it can do

- Add an expense with its name and amount
- See all added expenses
- Edit an expense
- Delete an expense
- Shows the total amount of expenses

## Technologies used

- Python
- Flask
- SQLite
- HTML
- CSS
